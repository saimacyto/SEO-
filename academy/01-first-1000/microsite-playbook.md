# The Microsite Playbook

The build-first path to your first $1,000.

Instead of finding a buyer first, you build a lead-generating microsite — then find someone
who'll pay for what it produces. Slower to first dollar (usually 30 to 60 days while the site
ranks), but you own the asset at the end.

## Pick this if

- You've tried freelancing and hated the dynamics.
- You'd rather build once and earn repeatedly than pitch new clients every week.
- You're comfortable spending ~$15 on a domain and ~$10/month on hosting.
- You can wait 30 to 60 days to see ranking before monetizing.

## Skip this if

- You want the absolute fastest path to first dollar. (→ see the
  [Upwork Playbook](./upwork-playbook.md) instead.)
- You don't have a small starting budget to invest.

## What you'll learn inside the playbook

- How to pick a niche and location where a single new site can rank.
- How to build and publish a microsite in a few hours using the One-Click Blueprint.
- How to rank it for buyer-intent keywords using semantic branching.
- How to monetize one of three ways: lease, local SEO client, or lead sale.
- How to use the same framework to scale into a portfolio later (→ Microsite Empire, inside
  Owner OS).
