# Rank Expand Academy — Knowledge Base

This is a running archive of the Rank Expand Academy course content, kept here so it can be
searched, referenced, and built on across sessions instead of living only in chat history.

Rank Expand Academy is training for the AI-first search landscape: outranking agencies,
getting exposure in AI Overviews, and turning traffic into revenue using semantic branching.
The core methodology is four things, nothing more:

- **Semantic Branching**
- **AI Overview Optimization**
- **Microsite Authority Stacking**
- **Purpose-driven Content Systems**

The program is structured as 11 modules (plus bonuses), meant to be worked in order, 5 days a
week, with weekly live reviews and checklists per module. Don't skip ahead.

There is a second, later-stage program called **Owner OS** (Owner OS, Microsite Empire, Agency
Engine) for scaling a business once you've already made your first money — not needed to start.

## How this archive grows

Each time new module content, templates, or workflows are shared, add a new numbered folder
(e.g. `02-...`) with a `README.md` capturing the material, following the pattern of the folders
above. Keep raw source material intact rather than summarizing away specifics (exact tool
names, playbook names, checklists) — those are what make this useful to come back to.
