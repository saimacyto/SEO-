# My Progress — Rank Expand Academy

This is a personal working log, separate from the course content archived under
[`academy/`](../academy/README.md). Course material there is the source content as taught;
everything here is your own application of it — decisions, action-item answers, and site
build history — kept as the running record the course keeps telling you to build (see
[Module 2, Action Item #2](../academy/02-limiting-beliefs/README.md#action-item-2--document-your-limiting-beliefs)
and [Module 5, Action Item #3](../academy/05-revenue-generating-activities/README.md#action-item-3--audit-your-last-7-days)).

## Contents

- [`niche-decisions/`](./niche-decisions/README.md) — every service+town combo evaluated for
  the Microsite Playbook, with Niche Validator numbers, the manual Google sanity check, and the
  final call, following [Step 1 of the Microsite Playbook](../academy/01-first-1000/microsite-playbook-step1-niche-and-town.md).
- [`site-builds/`](./site-builds/) — build and review history for each microsite once
  generated (Builder output review findings, fixes made, what's still pending), following
  [Step 3](../academy/01-first-1000/microsite-playbook-step3-build.md)'s "review and tighten"
  step.

## How this grows

- One file per niche decision under `niche-decisions/`, named `YYYY-MM-DD-service-town.md`.
- Add new top-level folders here for other action items or milestones as they come up (e.g.
  a `first-1k/` log once a client or lead deal lands).
- Keep entries factual and dated — the value is being able to look back and see what you
  actually knew/decided at the time, not a polished retelling later.
